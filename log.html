第一次跟段错误打交道，先怀疑自己

做了什么：按 README 的计划写指针练习，程序直接崩了，屏幕上只剩一行 Segmentation fault。第一次见，以为是编译器坏了。

卡在哪：用了一个没赋值的指针。后来加 -Wall -Wextra -g 编译，再靠 gdb 定位到是哪一行——原来编译器早就警告过，是我没看。

下一步：以后先看警告，再怀疑编译器。这条也写进笔记了。

2026-10-25#学习

先学 C 而不是 Python，这个决定我还在验证

做了什么：把这个问题认真想了一遍。选 C 的理由是：指针、内存、编译这些概念绕不过去，而且嵌入式那边全是 C。

卡在哪：C 写一个小东西要几十行，Python 三行就完了。中间好几次想放弃，转去写 Python。

下一步：先不换语言。等把指针和数组彻底写顺了，再用 Python 做 AI 那部分——两条腿走路，不用现在二选一。

空仓库的第一天：先把 README 写了

做了什么：发现自己那个 study.c 打开是"这里啥也没有"。决定先把 README 补上：这个仓库是干什么的、代码怎么跑、每周提交点什么。
